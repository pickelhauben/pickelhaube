# Fonts used to draw Open Graph images

These two files are only used at build time by `src/lib/og.ts` to draw the
link-preview images in `/og/`. Visitors never download them; the site itself
loads its fonts from Google Fonts.

| File                      | Typeface              | License                   |
| ------------------------- | --------------------- | ------------------------- |
| `SourceSerif4-Medium.ttf` | Source Serif 4 Medium | SIL Open Font License 1.1 |
| `Inter-Medium.ttf`        | Inter Medium          | SIL Open Font License 1.1 |

Both were downloaded from Google Fonts (<https://fonts.google.com>).
